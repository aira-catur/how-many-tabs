A tiny deterministic Python program (standard library only, no network) that
writes a single number — one honest, surprising count of open browser tabs,
digits only — to `entry.txt` in the output directory given by
`MAKEFUN_OUTPUT_DIR` (default `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
